# SmartFleetDatabase-G63
A relational database system for the Smart Fleet Management System that supports fleet operations, driver management, vehicle assignments, certification tracking, driver behaviour monitoring, maintenance management, and workshop operations.

HOW TO USE?
  Step 1: Download from github using the method of your choosing
  Step 2: Move your downloaded folder into htdocs folder of your XAMPP 
  	optional: but recommended, trim your downloaded folder into "SmartFleetDatabase-G63" bc Mr. Vu like it like this
  Step 3: Import sql file in the order: 
    + G63DBsystem(NoTrigger).sql -in /db structure/ - into your phpmyadmin
    + G63SUPERdummydata.sql -in /data/ - into the previously imported database
  Step 4: Add your phpmyadmin password into db.php, which is in /G63 Website/
  Step 5: Enter "localhost/downloaded folder's name/G63 Website"
	Step 6: Enjoy!
